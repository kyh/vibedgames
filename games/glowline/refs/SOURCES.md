# Reference shots

Review only. Never shipped, never committed (the PNGs are gitignored), never fed
to a generator. They set the production tier Glowline is held to, not its look:
Glowline keeps its own setting, palette, karts, circuits and HUD.

All four are live captures of Kartboard (https://kartboard.makio.io/), taken
2026-11-17 in headless Chromium at 1280×720 on a software GPU, which the game
itself classed as its "low" render tier. The real thing looks better than these.
