# Canopy Trail landmark

`public/landmark-tree.png` is a new transparent decorative sprite, generated with
the built-in image tool. Original game assets remain unchanged. Seven bounded
instances form three distant landmark groups; they have no collision or RNG.

The original background crops produced visibly cut-off crowns during a complete
flight, so this sprite replaces those added crops. It preserves the forest's
purple trunks, lime foliage and chunky pixels.
